# 移动端更新日志

这里记录 Termark 移动端的版本更新、问题修复和行为变更。

## v0.1.12（2026-08-04）

### 新增

- 支持由原生层管理终端后台连接状态。

### 修复

- 修复移动端会话可靠性和生命周期相关问题。
- 修复自适应布局和导航问题。
- 修复 Android 状态栏未与应用主题同步的问题。
- 修复从 iOS 实时活动进入应用时未复用已有终端的问题。

### 调整

- 优化主机来源切换器的界面和交互。
- 优化 AI 上下文主机选择器。
- 弱化 AI 聊天页标题栏的分隔线。

## v0.1.11（2026-08-04）

### 新增

- 终端长按方向手势支持根据滑动距离动态调整移动速度。

### 修复

- 恢复终端原生文本选择功能。

### 调整

- 优化终端停靠栏控件的样式。
- 移除使用音量键控制终端字体大小的功能。

## v0.1.10（2026-07-31）

### 新增

- 增加终端字体管理功能。
- 主机分组支持折叠和展开。
- SSH 连接支持使用跳板机。
- 增加主机凭证选择页面。
- 支持使用音量键调整终端字号。
- 终端支持长按方向手势、双击发送 Tab 键和手势触感反馈。
- 支持在终端中管理 Docker 容器和 systemd 服务。
- 云同步增加 Git 存储提供商。

### 修复

- 修复 AI 上下文选择器的交互问题。
- 修复终端连接回归问题。
- 修复官方云同步和 S3 同步的行为不一致问题。
- 修复弹窗和底部面板的滚动问题。
- 修复 Docker 详情页面的导航问题。
- 修复打开终端时媒体音量被改变的问题。
- 修复 iOS 终端双击手势触发文本选择的问题。
- 修复 iOS 应用退出后终端实时活动未结束的问题。
- 统一应用内显示的版本号。

### 调整

- 移动端适配 OIDC 双 Token 认证方案。
- 重构终端接口并接入公共 SDK，优化多会话下的原生终端视图管理。
- 云同步迁移至公共 SDK。
- 优化表单、设置页面、导航栏以及空状态和加载状态的交互。
- 在不可拖拽的底部面板中隐藏拖拽指示条。
- 版本设置页面的外部链接增加跳转标识。
