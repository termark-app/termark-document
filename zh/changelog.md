# 桌面端更新日志

这里记录 Termark 桌面端的版本更新、问题修复和行为变更。

更早版本请查看[更新日志归档（v1.0.47 及更早版本）](/zh/changelog-archive)。

## v1.6.6（2026-09-04）

### 新增

- SFTP 支持并发传输配置与任务队列，可并行执行多个上传/下载任务。
- SFTP 工作区新增文件选中数量提示。
- 终端主题新增 Termius Dark / Termius Light 两个配色。

### 修复

- 修复 tmux 当前会话探测失败影响会话列表的问题，旧版 tmux 切换会话降级为直接写入终端命令。
- 修复文件传输列表顺序错乱。

### 调整

- WebDAV 客户端改用预置 Basic 认证，消除每个同步会话的首请求双发。
- 重构云同步远端探测与状态缓存，连接状态检测更快更稳。
- 更新 AI 助手默认服务地址。

## v1.6.5（2026-09-02）

### 新增

- 支持工作区 SFTP 文件列表排序。
- 批量执行页新增断开终端一键重连。
- 新增终端密码凭据提示开关，并修复焦点恢复。

### 修复

- 修复批量执行终端背景透明度不一致。
- 修复错误中断后按大小续传可能固化损坏数据的问题。
- 修复 SFTP 工作区背景透明效果。
- 修复小文件上传完成后传输列表仍显示转圈、取消时报任务已完成的问题。

### 调整

- Windows 更新改为静默安装，重启后自动完成更新并拉起新版本。
- AI 助手名称改回「AI 助手」并清理重复的 compactHint 文案。
- 优化终端密码凭据弹层样式和透明效果。
- 传输任务不再同步文件权限，覆盖与新建均使用目标端默认语义。

## v1.6.2（2026-08-30）

### 新增

- 全局 AI 新增本机工具集（local_execute、local_file_read/write/edit、local_skill_read），复用现有审批管线，支持 `~/.agents/skills` 技能索引与本机工作目录配置。
- 全局 AI 新增工作目录切换、本地附件、项目约定注入（`AGENTS.md` / `CLAUDE.md`，64KB 上限）、手动压缩入口与后台长任务（`background` + `local_task_status`）。

### 修复

- 修复内存会话历史中失效压缩检查点未清空导致携带无用摘要。
- 修复手动压缩使用空会话 ID，并优化对话过短时的错误提示。

### 调整

- 重构上下文压缩：旧工具输出分级截断（最近 3 条保留全文、更早截断到 2000 runes）、压缩摘要预算从 16384 收紧到 4096 并增加长度与自包含约束、检查点移至对话开头以保留 system 前缀缓存、Anthropic 连续同角色消息合并。
- 完善 AI 上下文统计与压缩状态持久化，头部展示 token 用量与压缩状态。
- 手动压缩改为可追踪的 `conversation_compact` 事件（running/failed/succeeded），前端乐观插入并展示压缩前后用量。
- 重构 AI 输入工具栏与布局：加号菜单收纳附件/上下文/压缩、模型选择紧邻发送按钮、紧凑发送/停止按钮、透明对话框与顶部/头部布局优化。

## v1.6.0（2026-08-27）

### 新增

- 快速连接对话框支持多选与批量连接。
- Docker 面板支持普通用户 sudo 与 Podman，并将终端命令拼接后端化。
- 系统服务面板支持普通用户的用户级 systemd 服务。
- 新增 AI 消息复制为图片，并简化气泡样式。
- 支持忘记同步密码后强制覆盖云端数据。
- 新增打开日志文件夹入口。
- 为 Anthropic 对话启用提示词缓存。
- 新增 RouterOS 受限 Shell 专用适配器。
- 新增每小时自动检查更新。
- 支持 SSH 无密码连接并持久化认证方式。
- 增加文件夹加速下载并改用 tar.gz 分阶段传输。
- 增加标签双击行为设置并统一复制会话文案。
- 增加可同步的 SFTP 常用路径与快速跳转。
- 增加账户授权购买与管理入口。
- 增加 SSH 空闲连接池，CLI 与全局 AI 复用连接、空闲时长可配。

### 修复

- 修复终端密码提示弹窗失效，并重构检测逻辑。
- 修复 Windows RDP 文件启动方式。
- 兼容老版 systemd 查看服务日志报错。
- 修复老版 procps（如 CentOS 7）下打开进程详情报进程不存在。
- 修复终端关键词高亮不支持跨软折行匹配的问题。

### 调整

- 重构 AI 对话压缩为单次 Markdown 检查点，并提高模型输出预算（关闭 DeepSeek 压缩思考模式）。
- 优化 AI 自动审批退回重提流程，并暴露具体失败原因。
- 精简后端 AI 执行与安全判断，并移除 SSH 超时扩展。
- 迁移 AI 终端执行器到 SDK 并复用 RouterOS Shell，统一输出截断并增强 RouterOS 执行可靠性。
- 升级 Go 1.27 及依赖。
- 优化终端侧边栏功能引导。
- 优化 PRO 功能入口并限制快速删除。
- 改造加速上传为 tar.gz 分阶段传输。
- SSH 连接配置移入通用设置页，取消独立菜单页。
