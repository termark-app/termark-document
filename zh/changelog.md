# 桌面端更新日志

这里记录 Termark 桌面端的版本更新、问题修复和行为变更。

更早版本请查看[更新日志归档（v1.0.47 及更早版本）](/zh/changelog-archive)。

## v1.3.0（2026-08-09）

### 新增

- 端口转发支持配置本地监听地址和 IPv6 地址。
- 支持查看端口转发的活跃连接。

### 修复

- 修复 SSH Agent 使用多个密钥时的认证问题。
- 修复较旧版本 tmux 无法正常进入或切换会话的问题，并改善会话退出和当前客户端状态识别。
- 修复认证令牌轮换异常，并增强异常会话的自动恢复能力。
- 修复官方 AI 服务部分请求失败的问题。
- 修复 SFTP 面板隐藏期间上传完成后，文件列表未刷新的问题。
- 修复 SFTP 传输进度和状态的若干显示问题。
- 修复本地资产树中主机排序位置异常的问题。

### 调整

- 优化大规模进程列表的数据采集和刷新性能。
- 优化 AI 消息流式输出时的滚动体验。
- 在功能入口中标识付费功能，并调整专业运维和会话记录的权益划分。

## v1.2.0（2026-08-05）

### 新增

- 支持通过通用 HTTPS Git 仓库同步配置。
- 增加 systemd 系统服务管理，支持查看服务列表和详情。
- 增加跨平台 SSH Agent 认证，并在连接前校验认证授权状态。
- 增加终端渲染引擎配置，支持在运行时切换。
- 增加终端进程管理功能。
- 完善会话历史，支持按目录整理、导出和归档。
- 适配桌面端团队授权信息展示。

### 修复

- 修复 tmux 会话连接在不同 Shell 下的兼容性问题。
- 修复 SSH 交互式认证握手可能超时的问题。
- 修复云同步暂停后自动轮询可能发生竞态的问题。
- 修复关闭终端搜索后焦点未正确恢复的问题。
- 修复从 macOS Dock 启动时无法正确读取 SSH Agent 环境的问题。

### 调整

- 迁移终端指标采集，并完善 Docker 和 tmux 的跨平台兼容性。
- 优化 systemd 服务列表和详情页面样式。
- 统一停止操作的危险样式。
- 优化进程列表展示和启动时间格式。
- 统一会话录制导出，并优化历史记录操作按钮。
- 为 SFTP 文件列表增加前端排序。

## v1.1.6（2026-07-28）

### 调整

- 移除终端自动修改标签标题逻辑。

## v1.1.5（2026-07-28）

### 新增

- 增加 SFTP 文件信息查看功能。
- 支持通过 GitHub 同步配置，并支持 HTTP 和 SOCKS5 代理。
- 为 AI 执行命令增加说明。
- 增加终端延迟显示及开关。

### 修复

- 修复终端 WebGL 共享纹理图集导致的花屏问题。
- 修复全局 AI 主机名称缓存来源错误的问题。
- 修复已是最新版时误弹更新窗口的问题。
- 修复 AI 工具运行中取消状态异常的问题。
- 修复鼠标侧边返回按钮导致应用卡死的问题。
- 修复外观模式被云同步配置覆盖的问题。
- 修复 macOS 本地网络权限声明及国际化问题。

### 调整

- 优化全局 AI 主机名称展示，并移除工具详情中重复的主机名称。
- 统一终端 OSC 状态与通知处理。
- 重构 AI 工具执行与确认状态管理，并优化工具调用参数和输出样式。
- 区分 SSH 基础标题与 Agent 临时状态标题。
- 完善标签自定义标题与任务状态展示，并支持双击重命名。
- 将同步配置迁移为目录结构，并兼容旧路径迁移。
- 调整匿名统计为每四小时上报。
- 优化终端延迟指示器背景样式。

## v1.1.4（2026-07-20）

### 修复

- 使用固定应用协议，并修复快捷键监听初始化问题。
- 修复 AI 输入框行首空格导致文字重叠的问题。
- 修复 Windows 终端 Starship 图标显示问题。
- 区分普通与批量终端渲染器，并修复 WebGL 生命周期问题。
- 修复自定义主机 Logo 不显示的问题。

## v1.1.2（2026-07-18）

### 新增

- 增加授权信息手动刷新功能。
- 显示 AI 重试状态，并支持失败后重试。
- 资产树主机悬浮信息支持展示主机备注。

### 修复

- 恢复 SFTP 新建文件夹入口，并完善工具栏回调处理。
- 修复跟随系统语言时调整透明度闪烁的问题。
- 修复 macOS 下 Option+方向键无法按单词导航的问题。

### 调整

- 适配新版认证授权方案，登录改用单会话令牌，并按授权有效期判断本地功能可用性。
- 重构前后端同源加载，并优化 Electron 启动页。
- 优化 SFTP 文件列表自然排序。
- 优化命令片段分组展开交互。
- AI 输入框增加滚动条。
- 端口转发和历史记录操作按钮改为常显。
